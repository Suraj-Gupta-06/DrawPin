# DrawPin 2.0 Backend

The backend is not in `src/routeTree.gen.ts`. That file is generated by TanStack Router and should not be edited.

The backend entry file is:

```text
src/backend.ts
```

It exports the server-function API from:

```text
src/lib/api/drawpin.functions.ts
```

Server-only storage, sessions, seeded data, and password hashing live in:

```text
src/lib/backend/store.server.ts
src/lib/backend/types.ts
```

The current backend is functional for local standalone use. It includes auth, sessions, pins, comments, boards,
creators, services, orders, messages, and admin moderation. Data is stored in `.drawpin-data/db.json` when backend
functions are used.

For production, replace the storage adapter in `store.server.ts` with Postgres/Prisma/Drizzle, object storage for
artwork uploads, Stripe for payments, and Redis or database-backed sessions.
